# 日报与周报章节编号单一真源设计

## 状态

已确认，待实现。

## 问题与根因

日报模板在目录和正文标题中主动添加 `一、` 至 `十一、`。2026-07-13 与 2026-07-14 的日报 JSON 又把旧版展示编号写入各节 `title`，例如 `一、模型动态`、`三a、Agent 生态与实践`。渲染时两层字符串直接拼接，产生 `一、一、模型动态`、`四、三a、Agent 生态与实践`。

问题能够同时出现在目录和正文，是因为两处都使用相同的 `编号 + report.sections.*.title` 逻辑。列表圆点只是目录的列表样式，不是第二层章节号。

当前约束存在三个缺口：

- 日报和周报 schema 仅要求顶层章节 `title` 为字符串，没有禁止展示编号。
- 渲染测试只检查标题内容存在，没有检查编号唯一性及目录、正文一致性。
- `SKILL.md` 的终端示例仍使用旧版 `三a / 三b / 六a` 编号，容易诱导生成过程把展示编号复制到 JSON。

## 目标

- `report.json` 的顶层章节 `title` 只保存语义标题，不包含展示编号。
- 日报和周报模板是章节编号的唯一真源。
- 带展示编号的错误 payload 在渲染、归档、发送前失败。
- 目录和正文使用完全相同的一层编号。
- 修复 2026-07-13、2026-07-14 的本地日报 JSON 与 HTML，不重新发送邮件。

## 非目标

- 不调整新闻内容、编辑判断、章节顺序或邮件主题。
- 不改变条目标题、实验标题、深度观察标题等非顶层章节标题。
- 不修改历史发送状态，不补发或重发邮件。
- 不把章节名称改成固定常量，继续保留语义标题可配置能力。

## 方案

### 1. 编号所有权

模板继续负责展示编号：日报目录、日报正文、周报正文分别保留当前 `一、` 至 `十一、` 前缀。JSON 顶层章节只提供纯标题，例如 `模型动态`、`Agent 生态与实践`、`本周核心结论`。

渲染器不自动剥离错误前缀。自动剥离会隐藏数据契约违规，并让缓存 JSON、审计数据和最终 HTML 长期不一致。

### 2. Schema 守门

在日报和周报 schema 中分别增加可复用的 `sectionTitle` 定义，并让所有顶层章节 `title` 引用它。该定义要求非空字符串，并禁止以下开头：

- 中文章节号：`一、`、`十一、`、`三a、`、`六A、` 等。
- 常见阿拉伯数字章节号：`1、`、`1.`、`1)` 等。

约束只应用于 `sections` 下每个顶层 section 的 `title`，不应用于正文条目或其他嵌套对象的 `title`。

校验失败沿用现有错误边界：`render_html.py` 返回退出码 1，runner 不进入归档和发送阶段。

### 3. Skill 契约

在日报 JSON 产出步骤中明确写入：顶层章节 `title` 必须是纯语义标题，展示编号由模板负责。

终端简版示例同步为当前十一节连续编号：

1. 模型动态
2. Coding Agent 专项
3. 通用 Agent 动态
4. Agent 生态与实践
5. 方法论雷达
6. 硬数据信号
7. 跨条目模式
8. 本期建议实验
9. 决策雷达
10. 今日落地建议
11. 观察区 / 待核实

终端输出仍可带编号；只有 JSON `title` 禁止带编号。

### 4. 当前产物修复

从以下 payload 的十一节顶层标题中移除旧编号，其他字段保持不变：

- `cache/2026-07-13/report.json`
- `cache/2026-07-14/report.json`

使用仓库自带 `render_html.py` 重新生成两天的 cache HTML，再用 `archive.py` 更新 `reports/daily/` 中的本地归档。该流程不调用 `send_mail.py` 或 `finalize-daily`，因此不产生邮件投递。

## 测试策略

实现遵循 TDD：先新增回归测试并确认因现有 schema 放行编号化标题而失败，再修改 schema 和文档。

测试覆盖：

- 正常日报 fixture 的目录与正文各有十一节，文本完全一致且每节只有一层编号。
- 日报任一顶层 section 使用 `一、`、`三a、` 等前缀时，schema 校验失败。
- 周报任一顶层 section 使用编号前缀时，schema 校验失败。
- 嵌套条目标题即使以数字或中文数字开头也不受该规则影响。
- 现有日报、周报 fixture 继续成功渲染。
- 修复后的 2026-07-13、2026-07-14 HTML 不包含重复编号模式。

## 验收标准

- 日报目录和正文不再出现 `一、一、`、`四、三a、`、`十、七、` 等双重或错位编号。
- 周报保持单层连续编号。
- 编号化顶层章节标题无法通过 schema 校验。
- 项目完整测试集通过。
- 两天本地归档已刷新，邮件发送状态与外部收件箱不发生变化。

## 风险与控制

- 新 schema 会拒绝仍携带旧编号的历史 JSON。此次只迁移已确认受影响的 2026-07-13、2026-07-14；其他历史数据经检索均为纯标题。
- 禁止规则限定在顶层章节标题，避免误伤 `3D 模型`、`十一维评测` 等可能出现在条目标题中的正常文本。
- 不在模板中做静默兼容，以确保未来错误在发送前显式暴露。
