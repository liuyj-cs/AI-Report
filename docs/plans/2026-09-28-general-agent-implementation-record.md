# 通用与办公 Agent 改造实施与验收记录

本记录对应 [已确认计划](2026-09-28-general-agent-editorial-plan.md)。实现覆盖新日报 1.2、候选台账 1.1、周报 1.1；历史版本保持可读。日常生成仍从既有 runner 初始化开始，新 manifest 锁定版本。

## 已落地行为

- 通用与办公 Agent 只承载有明确工作任务的产品或能力变化；新增政策与风险观察。风险可以进入导读、雷达、模式与行动，不再需要伪装成产品。
- 产品说明任务、变化、能力形态、使用条件、影响和证据边界；风险说明状态、范围、决策影响和证据边界。实际产品漏洞/停服仍可以留产品栏目。
- 完整保存已返回工具响应，分块提供并重算覆盖；采集失败、实际空响应、编辑拒绝和未完整审查分开记录。初版只重算磁盘回执，不能证明内容实际完整提供；真实运行暴露的外层截断问题及后续修复见 [后续修复记录](2026-09-28-rerun-fixes.md)。
- 台账与正文双向一致，主张的直接证据与背景分开；每条行动依据分别受资格限制。行动必须交代相对前期的增量，风险不增加产品稀薄日的计数。
- 新周报通用栏目使用按任务归纳的有类型条目。跨栏目引用保留原日报位置并解释重新归类。历史行动需要补审时，使用周报目录内独立证据包，不改写原日报。
- 官方发现入口覆盖 Microsoft 365、ChatGPT 企业产品、Claude、Workspace、飞书和钉钉工作场景；办公专属查询覆盖昨日至今日，编码编辑器查询移到编码相关发现面。

主要实现：[编辑工作流](../../skills/ai-daily-report/workflows/general-agent-editorial.md)、[结构与行动校验](../../skills/ai-daily-report/scripts/agent_editorial.py)、[证据留存与重算](../../skills/ai-daily-report/scripts/evidence.py)、[日报模板](../../skills/ai-daily-report/templates/daily.html.j2)、[周报模板](../../skills/ai-daily-report/templates/weekly.html.j2)。现有 editorial、runner、tracking、三份 schema、来源配置与 skill 已同步接入。
